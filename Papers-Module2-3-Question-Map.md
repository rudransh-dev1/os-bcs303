## Conclusion

Module 2 contributes roughly 20–28 marks per paper (process states, PCB, IPC, threads, and always
one 8–14 mark CPU scheduling numerical). Module 3 contributes the same (critical section and
Peterson, semaphores with one classic problem, deadlock conditions/handling, and always one
10–14 mark Banker's algorithm numerical). Preparing these two numerical types plus the six
standard theory answers covers almost every Module 2 and Module 3 question in these seven papers.
